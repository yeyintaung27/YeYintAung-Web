# YYA Portfolio

A responsive, single-page portfolio built with React, TypeScript, Vite, and CSS.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Included sections

- Home
- About
- Education
- Skills
- Experience
- Projects
- Contact

The content is kept in `src/App.tsx` so the name, contact details, education, experience, projects, and social links can be updated in one place. The visual system lives in `src/styles.css` and uses the original warm paper, ink, terracotta, olive, and ochre palette. The Home portrait is stored at `public/profile.jpg`, and the temporary CV download is at `public/resume.pdf`.
